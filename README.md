# rmproxy-zotero

Keep a Zotero library and a reMarkable 2 (synced through a self-hosted rmfakecloud) in step: Zotero's items are mirrored onto the tablet by collection, and annotations and page edits made on either side appear on the other.

Primary use cases:

- **Class readings and papers**: often scanned PDFs, organised by course collection, marked up heavily, revisited in Zotero for notes and citations.
- **Books for personal reading**: EPUBs (typeset to PDF for the tablet) and PDF books, long documents read over weeks.
